## Getting Started

Clone the repository:

```bash
git clone https://github.com/samareshdalal/samaresh-portfolio.git
```

Open the project folder:

```bash
cd samaresh-portfolio
```

Then open `index.html` in your browser.

For development, you can also use VS Code with Live Server.
